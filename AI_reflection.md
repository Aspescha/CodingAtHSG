# AI Reflection

This document reflects on how we used AI tools during our project work. Our team consisted of people with different backgrounds and skill levels. Two of us had a data science background through the Data Science Fundamentals Certificate at the University of St. Gallen, while the others had different intermediate programming skills and strengths in areas such as project planning, idea generation, and application design.

AI helped us tremendously to get everyone on the same page. It allowed us to discuss programming and data science concepts more effectively, even when not all team members had the same technical background. This made collaboration easier and helped us understand concepts that would have been much harder to explain and implement without AI support.

We used several AI tools during the project:

-   **GitHub Copilot** for code completion, code suggestions, code review, and code cleaning.
-   **Claude Code** in both browser and CLI versions for methodological planning and for writing specific coding parts that were more complex than expected for an introductory programming course.
-   **ChatGPT** in both browser and Codex CLI versions for similar tasks as Claude, including project review, code explanation, notebook improvements, and setting up the `README.md` file.

At the same time, the project showed us that AI is only useful when the fundamental concepts are understood. Basic Python knowledge was necessary to get started, understand the suggestions, check whether the code made sense, and fix mistakes. AI could support us, but it could not replace the need to understand variables, loops, functions, data types, pandas operations, and the general structure of a Python project.

Our data science background was also important for structuring the project properly. The separation into data cleaning, exploratory data analysis, modeling, and application would not have worked as well without prior knowledge of how such a project is usually organized. AI helped us implement and improve parts of the project, but the overall direction, interpretation, and decisions still had to come from us.
